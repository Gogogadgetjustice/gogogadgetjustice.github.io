Steam Library Spec Checker

Pull your Steam library, save it as JSON, compare against your system specs, and export a run-it report.

1. Load your Steam library

Uses the official Steam Web API (IPlayerService/GetOwnedGames) via a CORS proxy (corsproxy.io). You need a free Steam Web API key from steamcommunity.com/dev/apikey (any domain name works for personal use, e.g. "localhost"). The key is only stored in your browser. Your profile's game list must be set to public (Steam > Edit Profile > Privacy Settings > Game details: Public).

2. Your library

3. Your system specs

Browsers can't read full hardware info, so auto-detect fills in what it can — fill in / correct the rest yourself.

4. Check what you can run

Steam doesn't expose machine-readable system requirements via API, so for each game this pulls the "Minimum"/"Recommended" requirements text from its store page (via the same CORS proxy) and runs a best-effort comparison against your specs (CPU/GPU name matching + RAM/VRAM numbers). Always treat results as a rough guide — verify anything borderline on the store page itself.
